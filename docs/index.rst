Quick Start
----------

.. code-block:: bash

   # Clone the repository
   git clone https://github.com/tcorbet994/sovereign-protocol.git
   cd sovereign-protocol

   # Initialize the system
   python init.py

   # Start the interface
   python -m sovereign_control

   # Access the web interface at http://localhost:8000
